# webSchool — платформа для тематических курсов

Учебная платформа на React, TypeScript и Vite. В каталоге собраны самостоятельные направления с собственными разделами и уроками. Сейчас доступны SQL, JavaScript, Python и полный курс Docker — от основ контейнеризации до production.

## Добавление направления

Каждое направление — отдельный модуль в `src/courses/<id>/course.ts`. Каталог автоматически обнаруживает модули, поэтому для нового направления не нужно менять приложение или реестр вручную.

Модуль курса экспортирует объект `CourseModule` с описанием, разделами и уроками. Урок может содержать краткое объяснение, список подробностей (`details`), пример кода (`example`), ожидаемый результат (`exampleOutput`), задание и подсказку. Примеры структуры и содержания есть в папках `src/courses/javascript` и `src/courses/python`. Уроки без собственного интерактивного компонента используют общий просмотрщик и могут отмечаться пройденными. Для специфической практики курс может предоставить компонент `Activity`, а для справочного блока — `Aside`.

SQL — отдельное направление со своими материалами в `src/lessons`, SQL-интерпретатором и компонентами практики в `src/courses/sql`. Новые темы SQL можно добавлять в существующую структуру уроков, не меняя оболочку сайта.

Переиспользуемые UI-компоненты находятся в `src/ui-kit`.

## Запуск

```sh
npm install
npm run dev
```

В SQL-курсе запускай запросы кнопкой или сочетанием `⌘/Ctrl + Enter`.

## Сборка

```sh
npm run build
```
