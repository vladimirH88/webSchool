# SQLook — интерактивный тренажёр SQL

Учебное приложение на React, TypeScript и Vite. В программе 40 тем, разбитых на 7 уровней: основы SQL, агрегация, соединения, подзапросы и модификация данных, аналитика, проектирование БД, оптимизация и администрирование. Каждый урок хранится в своей папке внутри `src/lessons`.

Практические запросы выполняются по демонстрационной таблице `employees`. Песочница исполняет учебный поднабор `SELECT`: `WHERE`, сравнения, `AND`/`OR`, `LIKE`, `IN`, `DISTINCT`, `ORDER BY`, `LIMIT`, псевдонимы, агрегаты `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY` и `HAVING`. Остальные темы содержат теорию и примеры SQL в режиме чтения; они не исполняются песочницей. Это не полноценный PostgreSQL.

Переиспользуемые компоненты интерфейса находятся в `src/ui-kit`. Каждый компонент хранится в отдельной папке вместе со своими стилями; общий публичный API собран в `src/ui-kit/index.ts`.

## Запуск

```sh
npm install
npm run dev
```

Нажми «Запустить запрос» или используй `⌘/Ctrl + Enter` в редакторе.

## Сборка

```sh
npm run build
```
